# 🔐 SecurePass – Password Security Analyzer

SecurePass is a web-based Password Security Analyzer developed as part of **Task 03 of the Prodigy InfoTech Cyber Security Internship**.

The application analyzes passwords based on different security criteria and provides users with a **security score, password strength, risk level, security checks, and recommendations** to help create stronger passwords.

---

## ✨ Features

- 🔑 Password strength analysis
- 📊 Security score
- 🛡️ Strength and risk level detection
- 🔠 Uppercase and lowercase character checks
- 🔢 Number detection
- ✨ Special character detection
- 🔁 Repeated character detection
- ⚠️ Predictable sequence detection
- ⌨️ Common keyboard pattern detection
- 💡 Password improvement recommendations
- 👁️ Show/Hide password option
- 🎨 Modern and responsive cybersecurity-themed UI

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/anushkayms/PRODIGY_TASK3.git
```

Navigate to the project folder:

```bash
cd PRODIGY_TASK3/SecurePass
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Then open the application in your browser:

```text
http://127.0.0.1:5000
```

---

## 🔍 How It Works

1. Enter a password.
2. Click **Analyze Password**.
3. SecurePass checks the password for complexity and potential weaknesses.
4. The application displays:
   - Security Score
   - Password Strength
   - Risk Level
   - Security Checks
   - Recommendations

---

## 🔒 Privacy

Passwords are analyzed only for the current session and are **not permanently stored or saved in a database**.

## 📌 Internship Task

### Task 03 – Password Complexity Checker

The objective of this task is to assess the strength of a password based on criteria such as:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

SecurePass provides feedback and recommendations to help users create stronger and more secure passwords.
